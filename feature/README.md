# Features Overview — MPRD

Quick summary of features included in **[MPRD - Modern Pill Run Dialog](../README.md)** (`v1.2.0`).

## Feature List
- **4 Crafted Themes:** Minimal 11, Translucent (Apple Glass), Frosted Light (Apple Light Glass), and Midnight Aurora.
- **Seamless Apple Glass Blur:** Creamy 3-pass frosted blur with vibrancy and adjustable transparency (`10% – 100%`).
- **DirectWrite Smooth Typography:** Anti-aliased, non-pixelated font rendering with **Google Sans** default and custom font input.
- **Responsive Pill Window (`WIDTHxHEIGHT`):** Auto-scales icons, buttons, radius, and typography cleanly across `720p`, `1080p`, `1440p`, and `4K`.
- **Polished Micro-Animations:** Slow top-to-bottom open/close glides, smooth hover animations across every control, gradient hover sweep on the centered Run button, typing feedback, and a luminous 360° icon spin before launching.
- **Smart Windows Integration:** Native `RunMRU` history sync, inline ghost autocomplete (`Tab`), 1-click Admin Mode toggle (`Ctrl + Shift + Enter`), authentic Bottom-Left (Classic) positioning, Taskbar visibility toggle, and Cursor Drag toggle.

# Ringkasan Fitur — MPRD

Ringkasan singkat fitur pada **[MPRD - Modern Pill Run Dialog](../README.md)** (`v1.2.0`).

## Daftar Fitur
- **4 Tema Pilihan:** Minimal 11, Translucent (Apple Glass), Frosted Light (Apple Light Glass), dan Midnight Aurora.
- **Blur Seamless Apple Glass:** Frosted blur 3-pass yang mulus dengan pengaturan transparansi `10% – 100%`.
- **Teks Halus DirectWrite:** Bebas pecah/pixelated dengan default **Google Sans** dan dukungan custom font favorit.
- **Pill Window Responsif (`LEBARxTINGGI`):** Otomatis menyesuaikan ukuran icon, tombol, radius, dan font untuk layar `720p`, `1080p`, hingga `4K`.
- **Animasi Polish Lengkap:** Animasi buka/tutup dari atas ke bawah, hover halus di seluruh tombol & dropdown, tombol Run center dengan gradasi hover, efek ketik, dan putaran 360° bercahaya sebelum menjalankan perintah.
- **Integrasi Windows Lengkap:** Sinkronisasi history `RunMRU`, autocomplete instan (`Tab`), Admin Mode 1-klik (`Ctrl + Shift + Enter`), posisi Bottom-Left (Classic), opsi tampil di Taskbar, dan opsi drag dengan kursor.
