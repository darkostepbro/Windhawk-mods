| :--- | :---: | :---: | :--- |
| **MPRD - Modern Pill Run Dialog** | `1.2.0` | `explorer.exe` (`Win + R`) | [`modern-pill-run-dialog.wh.cpp`](../modern-pill-run-dialog.wh.cpp) |

## Highlights — MPRD (`v1.2.0`)
- **4 Themes:** Minimal 11, Translucent (Apple Glass), Frosted Light (Apple Light Glass), Midnight Aurora.
- **Seamless Blur & Transparency:** Creamy Apple Glass frosted blur + `10% – 100%` transparency control.
- **DirectWrite Smooth Font:** Crisp anti-aliased rendering with **Google Sans** default + custom favorite font input.
- **Responsive Sizing:** `Pill Window (px)` (`WIDTHxHEIGHT`) auto-scales for `720p`, `1080p`, `1440p`, and `4K`.
- **Polished Animations:** Top-to-bottom open/close glides, smooth hover animations across all controls, centered Run button with gradient hover, and a 360° glowing launch spin.
- **Windows Integration:** Native `RunMRU` history, inline autocomplete, 1-click Admin Mode, Classic Bottom-Left mode, Taskbar icon toggle, and Cursor Drag toggle.

*(Full bilingual documentation is built directly into [`modern-pill-run-dialog.wh.cpp`](../modern-pill-run-dialog.wh.cpp) for display inside the Windhawk app.)*
