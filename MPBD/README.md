# MPBD - Modern Pill Bar & Dock

Transforms your Windows desktop with a lightweight, native C++ **Modern Pill Bar & Live Widget Dock** — built with **zero WebView2 overhead**, **Lucide vector icons**, **DirectWrite smooth typography**, and unified themes matching **MPRD**.

## Layout Styles
1. **Split Pill Islands** — Three independent floating islands (**Left:** Start, MPRD Quick Run, Active Window · **Center:** Running Apps Dock · **Right:** Modular Live Widgets) with 100% click-through desktop space in between.
2. **Single Floating Dock** — One unified floating capsule bar along the top or bottom screen edge.
3. **Edge-to-Edge Seamless** — Full-width flush desktop status bar.

## Themes
1. **MPBD Blur** — Seamless dark Acrylic frosted blur with balanced luminosity and subtle micro-grain.
2. **MPBD Legacy** — Classic obsidian matte bar with crisp rim lighting and soft shadow.
3. **M-11 Compact** — Flat minimal dark bar (`#121214`) with crisp `1px` border.
4. **Liquid Glass** — Translucent convex liquid glass islands with bright top/bottom specular rims and liquid hover lenses.
5. **Midnight Aurora** — Deep indigo-obsidian frosted glass with cyan-to-violet ambient rim gradient.
6. **Daylight Frost** — Bright milky frosted light glass with dark slate Lucide icons & text for light wallpapers.

## Live Interactive Widgets & Controls
- **Start & Quick Run:** Left-click Start to open the Windows Start Menu; click the Search icon to directly launch **MPRD** (`Win + R`).
- **Active Window Pill:** Displays the live icon and title of the currently focused application.
- **Running Apps Dock:** High-DPI 32-bit ARGB app icons with hover zoom lens and active indicator pill (**Left-click** to focus/minimize, **Middle-click** to close window).
- **Media Controls:** Automatically detects active music track titles (Spotify, Apple Music, Foobar2000, MusicBee, AIMP) with **Previous / Play-Pause / Next** buttons.
- **CPU & RAM Usage:** Lightweight real-time kernel telemetry (click to open Task Manager).
- **Network Throughput:** Live download/upload speed indicator (click for Network Settings).
- **Volume Control:** **Scroll mouse wheel** over the volume pill to adjust system volume, **Left-click** to mute/unmute, **Right-click** for Sound Settings.
- **Battery Status:** Live percentage & charging bolt indicator (auto-hidden on desktop PCs without a battery).
- **Clock & Calendar:** 24-hour or 12-hour date & time (click to open Windows Notification & Calendar center).
- **Quick Settings:** Far-right sliders button opens Windows Quick Settings (`Win + A`).
- **Drag-to-Reorder Widgets:** Hold **`Alt + Left-Drag`** on any right-side widget to reorder widgets live on the bar (saved automatically).

# MPBD - Modern Pill Bar & Dock (Bahasa Indonesia)

Menghadirkan **Status Bar, App Dock, & Live Widget Islands** modern yang sangat ringan berbasis C++ native (tanpa WebView2/Chromium yang boros RAM), menggunakan **Lucide Vector Icons (`24x24`)**, **DirectWrite anti-pecah**, dan ekosistem tema yang seragam dengan **MPRD**.

## Gaya Layout & Tema
- **3 Gaya Layout:** **Split Pill Islands** (3 kapsul melayang terpisah dengan sela tembus klik), **Single Floating Dock** (1 kapsul melayang), dan **Edge-to-Edge Seamless** (bar penuh ujung ke ujung di atas atau bawah layar).
- **6 Pilihan Tema:** **MPBD Blur**, **MPBD Legacy**, **M-11 Compact**, **Liquid Glass**, **Midnight Aurora**, dan **Daylight Frost**.

## Interaksi & Pintasan Cepat
- **Klik Icon Search:** Langsung membuka **MPRD Run Dialog**!
- **App Dock Tengah:** **Klik Kiri** untuk fokus/minimize aplikasi, **Klik Tengah (Scroll Click)** untuk menutup aplikasi.
- **Widget Volume:** **Scroll Roda Mouse** tepat di atas widget volume untuk menaikkan/menurunkan suara, **Klik Kiri** untuk Mute, **Klik Kanan** untuk pengaturan suara.
- **Atur Ulang Posisi Widget:** Tahan **`Alt + Drag Kiri`** pada widget di sisi kanan untuk menggeser urutannya secara langsung (tersimpan otomatis).
- **Integrasi Desktop Cerdas:** Mengunci area kerja jendela maximize (`SHAppBarMessage`), otomatis sembunyi saat bermain game fullscreen, serta opsi menyembunyikan Taskbar bawaan Windows secara aman.
